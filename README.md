# 1Example-Cogs

My cog repo for [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot), a multi-function Discord bot.

## Installation

Make sure you have the `downloader` cog loaded first:

```
[p]load downloader
```

Then add this repo and install a cog:

```
[p]repo add 1example-cogs https://github.com/<your-github-username>/1Example-Cogs
[p]cog install 1example-cogs <cog>
[p]load <cog>
```

## Cogs

| Name | Description |
| --- | --- |
| [DashboardBridge](dashboardbridge/README.md) | Generic Dashboard settings pages for any loaded cog that doesn't ship its own Dashboard integration. |
